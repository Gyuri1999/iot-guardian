# Αληθινό εργαστήριο: ESP32 και Mosquitto

Προαιρετικό. Ο ίδιος κώδικας που γράφεις στο παιχνίδι φλασάρεται σε αληθινό ESP32 και τα μηνύματα περνούν από αληθινό Mosquitto στον υπολογιστή σου. Τα μαθήματα και οι έλεγχοι γίνονται πάντα στην προσομοίωση. Το αληθινό εργαστήριο είναι για να δεις το ίδιο πράγμα να δουλεύει «στ' αλήθεια».

> Μόνο για δικές σου συσκευές, στο δικό σου δίκτυο.

## Τι χρειάζεσαι

- ESP32 DevKit (ESP32-WROOM-32) και καλώδιο USB **δεδομένων**.
- macOS με Homebrew και Node.js.
- `brew install arduino-cli mosquitto`
- Το πακέτο ESP32 και οι βιβλιοθήκες:

```bash
arduino-cli core install esp32:esp32
```

```bash
arduino-cli lib install PubSubClient "DHT sensor library" "Adafruit Unified Sensor" ArduinoJson
```

## Συνδεσμολογία (όπως στο παιχνίδι)

| Εξάρτημα | Σύνδεση |
|---|---|
| LED | GPIO 2 → αντίσταση 220 Ω → άνοδος LED, κάθοδος → GND. Τα περισσότερα DevKit έχουν ήδη LED στο GPIO 2. |
| Κουμπί | Ένα πόδι στα 3V3, το άλλο στο GPIO 15 και μέσω 10 kΩ στο GND. Πατημένο = HIGH, όπως στο παιχνίδι. |
| PIR (HC-SR501) | VCC → VIN (5 V), GND → GND, OUT → GPIO 4 |
| DHT22 ή DHT11 | VCC → 3V3, GND → GND, DATA → GPIO 13 (με 10 kΩ προς 3V3 αν δεν είναι πλακέτα-module) |

| HC-SR04 | VCC → VIN (5 V), TRIG → GPIO 5, ECHO → GPIO 18 **μέσω διαιρέτη τάσης** (π.χ. 1 kΩ + 2 kΩ, γιατί το ECHO βγάζει 5 V), GND → GND |
| Φανάρι | Κόκκινο → GPIO 25, κίτρινο → GPIO 26, πράσινο → GPIO 27, το καθένα με αντίσταση 220 Ω, κοινό GND |

Το GPIO του DHT και ο τύπος του ορίζονται στο `--setup`.

## Εκκίνηση

Από τον φάκελο του παιχνιδιού:

```bash
node real-lab/helper.js --setup
```

Ρωτά όνομα και κωδικό WiFi (2,4 GHz), GPIO και τύπο DHT. Τα αποθηκεύει **μόνο** στο `real-lab/secrets.json`, με δικαιώματα μόνο για σένα. Η σελίδα δεν τα βλέπει ποτέ. Μπαίνουν στο firmware τη στιγμή του compile.

```bash
node real-lab/helper.js
```

Μετά άνοιξε το http://localhost:8787. Κάτω από τον κώδικα κάθε άσκησης εμφανίζεται το πάνελ **Αληθινό ESP32**:

- **Ασκήσεις κώδικα:** διαλέγεις θύρα USB και πατάς **Φλάσαρε στο ESP32**. Βλέπεις το compile, το upload και μετά το αληθινό Serial. Τα λάθη του compile δείχνουν τη γραμμή του δικού σου κώδικα.
- **Ασκήσεις ρυθμίσεων:** το **Εφάρμοσε στον αληθινό broker** τρέχει τον Mosquitto με τις ρυθμίσεις σου (θύρες, TLS, χρήστες, ACL). Το **Ανοιχτό εργαστήριο** γυρίζει σε θύρα 1883 χωρίς υποχρεωτικό κωδικό.
- **Πιστοποιητικά TLS:** φτιάχνει δική σου CA και πιστοποιητικό για την IP του Mac. Το `HOME_CA` στο ESP32 δείχνει σε αυτή την CA.
- **MQTT (αληθινό):** όλα τα μηνύματα που περνούν από τον broker, και φόρμα για publish (π.χ. `home/led/set`, `{"cmd":"on"}`).

## Πώς δουλεύει

- Το `helper.js` ακούει μόνο στο `127.0.0.1:8787` και δέχεται εντολές μόνο από τη δική του σελίδα (έλεγχος Host και Origin).
- Πριν το φλάσαρισμα, ο κώδικας περνά τον ίδιο έλεγχο με την προσομοίωση. Μετά προστίθεται το `#include "IoTGuardian.h"` και κάθε `"κείμενο"` γίνεται `String("κείμενο")`, ώστε το `"Temp: " + x` να ενώνει κείμενο όπως στο παιχνίδι.
- Το `IoTGuardian.h` αντιστοιχίζει τις εντολές του παιχνιδιού σε αληθινές βιβλιοθήκες:

| Παιχνίδι | Αληθινή βιβλιοθήκη |
|---|---|
| `mqtt.*` | PubSubClient, με ουρά για `mqtt.read()` |
| `readTemperature()` | DHT |
| `jsonGet` | ArduinoJson |
| `WiFi.begin` | WiFi |

  Το `delay()` αφήνει τον MQTT client να λαμβάνει μηνύματα όσο περιμένει.
- Ο Mosquitto τρέχει ως child process. Ακούει στις θύρες των ρυθμίσεων για το ESP32 και στο `127.0.0.1:9001` (WebSocket) για τη σελίδα. Η σελίδα συνδέεται με έναν τυχαίο κωδικό παρακολούθησης (`guardian-monitor`), που αλλάζει σε κάθε εκκίνηση.
- Έλεγχος ότι όλες οι λύσεις κάνουν compile για ESP32, χωρίς πλακέτα:

```bash
node tools/real-compile.js
```

## Συχνά προβλήματα

- **Δεν βρέθηκε πλακέτα:** δοκίμασε άλλο καλώδιο (πολλά είναι μόνο φόρτισης). Για CH340 ή CP210x ίσως χρειάζεται driver.
- **Το upload κολλάει στο «Connecting…»:** κράτα πατημένο το BOOT μέχρι να ξεκινήσει.
- **Το ESP32 δεν συνδέεται στον broker:**
  - Το ESP32 και ο Mac πρέπει να είναι στο ίδιο δίκτυο.
  - Επίτρεψε στο macOS τις εισερχόμενες συνδέσεις του mosquitto, αν ρωτήσει.
  - Αν τρέχει άλλος broker, σταμάτα τον με `brew services stop mosquitto`.
- **Η IP του Mac άλλαξε:** φλάσαρε ξανά. Μετά την αλλαγή IP χρειάζονται και νέα πιστοποιητικά TLS.

## Γνωστοί περιορισμοί

- Το `Serial.println` ενός `bool` τυπώνει `1`/`0` στην πλακέτα και `true`/`false` στο παιχνίδι.
- Το TLS με πιστοποιητικό για IP είναι ελεγμένο με `mosquitto_pub`. Σε πλακέτα, η επαλήθευση εξαρτάται από την έκδοση του mbedTLS. Αν αποτύχει, κοίτα το Serial.
- Στον ύπνο κάποιες πλακέτες χάνουν για λίγο τη θύρα USB. Το Serial ξαναρχίζει όταν ξυπνήσει η πλακέτα.
